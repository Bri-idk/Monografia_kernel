# Monografía: El Kernel & Sistemas Operativos

Proyecto web informativo desarrollado con **HTML5**, **CSS3** y **Bootstrap 5**, enfocado en explicar de manera clara, concisa y visual qué es un kernel, cómo administra el hardware y su relación con Linux y los sistemas operativos.

---

## 📌 Temas abordados

- **¿Qué es un Kernel?** Concepto fundamental y rol como puente entre software y hardware.
- **Funciones principales:** Administración de memoria RAM, gestión de procesos de CPU y controladores de dispositivos.
- **Linux vs. Sistema Completo:** Diferencia entre el núcleo Linux y las distribuciones completas.
- **Tipos de Arquitectura:** Comparativa rápida entre arquitecturas monolíticas y microkernel.

---

## 🛠️ Componentes de Bootstrap utilizados y editados

- **Navbar:** Adaptada con tema oscuro (`data-bs-theme="dark"`), marca personalizada y enlaces alineados a la derecha mediante márgenes automáticos (`ms-auto`).
- **Carousel:** Carrusel de imágenes estilizado con `object-fit: cover` para mantener proporciones uniformes y textos flotantes (`carousel-caption`) con fondo semitransparente para máxima legibilidad.
- **Grid System (`row` & `col`):** Estructuración responsiva (`row-cols-1 row-cols-md-2 g-4`) para ordenar las secciones informativas en cuadrícula adaptable a móviles y pantallas de escritorio.
- **Cards & List Groups:** Tarjetas con altura uniforme (`h-100`), fondos oscuros y listas integradas para desglosar funciones técnicas.
- **Footer:** Pie de página semántico con estilos de utilidad de Bootstrap y enlaces externos.

---

## 🎨 Personalización CSS (`styles.css`)

- **Fondo global:** Paleta oscura (`#141414`) para una estética tipo terminal/dark mode.
- **Acentos de color:** Clase personalizada (`.texto-morado` en `#bb86fc`) para dar contraste visual a los encabezados de las tarjetas.
- **Enlaces:** Estilos limpios y efectos hover para navegación y autoría.
